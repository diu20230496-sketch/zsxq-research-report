散热成为今日最强主线，液冷（鸿富瀚阿里2GW起量、鼎通科技英伟达供应链cage液冷量产）与金刚石（四方达CVD散热片热导率超2000进入小批量供货、华为韬定律下晶体管3D密度散热瓶颈逻辑强化）双轮并进。金刚石板块当日涨幅显著：四方达+20%、惠丰钻石+20%、力量+15%。

剑桥科技配售1560万股净筹19.67亿港元（折让仅8.88%），揭示光模块竞争终局是"资金驱动的军备竞赛"。1.6T光模块Q2启动放量，有源背板成为1.6T+时代必选项，CPO用高功率CW和FAU处于验证阶段（仕佳光子对标LITE国际领先）。

3. [功率器件/被动元件] 英飞凌第二波涨价函确认定价权转移，MLCC产能错配至2027年

英飞凌7/1实施第二波涨价，直接把"需求超预期爆发"写进函件——这不是成本传导，而是高景气度下的定价权转移。MLCC高容料号现货价5月已涨70-80%，产能缺口至少持续到2027年（高端产能无法从中低端转产，挤出效应20-25%）。

第三层｜PART2 核心主题深度拓展

主题一：散热产业链全面升温——液冷+金刚石双轮驱动

一、概念的形成与演化

  • 起源：AI算力密度提升（单芯片功耗从300W→1000W+）导致传统风冷/水冷无法满足散热需求，液冷成为数据中心标配。金刚石散热源于半导体材料科学突破——金刚石热导率（2000+ W/m·K）是铜的5倍、硅的15倍。
  • 关键拐点：
  • 2024年：英伟达GB200首次采用液冷方案，液冷从"可选"变为"必选"
  • 2025年2月：天风通信底部推荐金刚石板块
  • 2026年5月：华为提出"韬定律"，强调晶体管3D密度带来的散热瓶颈，金刚石散热逻辑强化
  • 2026年5月28日：四方达CVD金刚石散热片热导率超2000，通过海外客户测试，进入小批量供货（从0到1产业化落地）
  • 阶段判断：液冷处于快速成长期（GB200放量、阿里2GW招标）；金刚石处于产业导入期→快速成长期过渡（送样验证→小批量供货→产业化落地）

二、产业链结构全景

  • 上游：冷却液（氟化液/水基）、泵阀管路、金刚石材料（CVD设备、石墨原料）、铜/铝基材
  • 中游：液冷板/冷板模组（鸿富瀚、鼎通科技）、液冷系统解决方案（安腾创新/大族激光）、金刚石散热片（四方达、沃尔德、国机精工）、金刚石钻针（中钨高新、欧科亿）
  • 下游：AI数据中心（阿里、字节、Meta、Amazon）、半导体制造（晶圆划片/减薄）、消费电子（手机芯片散热）、光模块散热
  • 价值链分布：液冷端——解决方案商（30-40%毛利率）＞零部件（20-30%）；金刚石端——散热片（单片近3万元，高毛利）＞钻针＞工业金刚石粉
  • 国产替代进展：液冷——国产已主导（阿里系、华为系自研+外包）；金刚石——全球90%产能在中国，但高端CVD大单晶片仍依赖进口设备（MPCVD），国产设备正在追赶

三、当前发展状态

  • 液冷技术成熟度：量产爬坡期。冷板方案成熟，浸没式液冷在验证；Q2-Q3为产能释放关键窗口（鼎通首条产线Q2末投产、鸿富瀚Q2起量）
  • 金刚石技术成熟度：从实验室→中试→小批量供货跨越。四方达进入小批量供货是关键里程碑；华为可能明年底超节点试用复合方案
  • 商业化进度：液冷26年预计大规模放量（阿里2GW、英伟达GB200）；金刚石今年完成0到1，27-28年有望规模化
  • 政策："东数西算"、算力基础设施节能降碳政策推动液冷渗透率提升；无直接金刚石产业政策，但纳入半导体材料自主可控大框架

四、竞争格局、壁垒与政策环境

  • 液冷竞争格局：
  • 设备+方案一体化：大族激光（收购安腾，创始人来自维谛技术）——跨赛道整合
  • 零部件/模组：鸿富瀚（阿里系+海外电站）、鼎通科技（英伟达供应链cage液冷）
  • 新兴：华为系自研液冷
  • 金刚石竞争格局：
  • 四方达：4英寸CVD金刚石片，初步年产能2.5万片→扩产到10-12万片，海外二次送样储备阶段
  • 沃尔德：12英寸薄膜，间接对接海外，GPU/手机芯片/光模块多客户验证
  • 国机精工：6英寸片+金刚石复合方案（铜/碳化硅），和华为对接
  • 力量钻石：和台湾捷斯奥合作散热片，对接海外
  • 进入壁垒：液冷——客户认证周期长（6-12个月）、产能爬坡慢；金刚石——CVD设备昂贵（MPCVD单台数百万）、工艺良率低（热导率一致性难控制）、认证周期长（从送样到小批量供货需6-12个月）
  • 潜在监管风险：液冷冷却液环保约束（氟化液GWP值）；金刚石无显著监管风险

五、需求测算与空间展望

  • 液冷需求：阿里26年新增2GW负载，首批500MW已招标，假设液冷价值量占数据中心Capex 8-10%。鸿富瀚26年液冷收入预计18亿；鼎通单套2000元×60万套=12亿收入，满产150万套=30亿。全球AI数据中心液冷市场：2026年预计超100亿美元
  • 金刚石需求：单片4英寸金刚石片覆盖1个GPU，单价近3万元。英伟达2026年预计出货500万颗GPU量级，若10%采用金刚石散热=50万片=150亿市场。复合方案（金刚石+铜/碳化硅）性价比更高，商业化更快，单价低于纯金刚石。钻针：PCB材料升级（M9/M10/PTFE）拉动金刚石微钻需求，欧科亿看至少100亿增量
  • 敏感性：液冷——数据中心Capex增速；金刚石——GPU功耗升级节奏、华为超节点试用进度

六、商业模式升级路径

  • 液冷：从"卖零部件"（冷板/模组）→"卖解决方案"（全链条液冷系统）→"卖服务"（运维+能耗管理）。大族激光收购安腾就是"零部件→解决方案"的升级
  • 金刚石：从"工业金刚石工具"（低毛利）→"半导体散热材料"（高毛利，单片3万）→"第四代半导体衬底"（远期空间）。价值量跃升10倍以上
  • 定价权演变：液冷——标准化产品（价格接受者）→差异化解决方案（价格制定者）；金刚石——稀缺材料（超级定价权，全球90%产能在中国）

七、认知偏差与市场博弈

  • 主流叙事陷阱：市场把金刚石当作"概念炒作"，忽视了四方达已进入小批量供货的实质性进展。"2月底部推荐"至今仍被当作"底部"，但板块当日涨幅（四方达+20%、惠丰钻石+20%）显示股价已高
  • 共识与现实的鸿沟：机构预期液冷Q2起量，但产能爬坡和客户认证可能延迟；金刚石0到1产业化"预计今年完成"，但规模化放量可能需要到2027-2028年
  • 信息不对称：卖方看到产能规划和客户送样进度；买方看到股价涨幅和板块热度；产业一线看到实际良率和成本——三方存在时滞
  • 反身性：金刚石板块持续上涨→企业融资能力增强→扩产加速→产业落地提前（正反馈）。但如果良率瓶颈未突破，回调幅度可能很大
  • 如果错了会怎样：液冷——若AI数据中心Capex不及预期，阿里2GW延迟，鸿富瀚/鼎通收入增速下调；金刚石——若华为超节点试用推迟，或复合方案替代纯金刚石，四方达等估值回撤

主题二：光通信产业链升级——从光模块到互联方案

一、概念的形成与演化

  • 起源：数据中心内部流量从100G→400G→800G→1.6T升级，光模块从可插拔→CPO（共封装光学）→有源化互联方案演进
  • 关键拐点：
  • 2023-2024：800G光模块放量，中际旭创/新易盛成为龙头
  • 2025：1.6T光模块开始送样，CPO概念兴起
  • 2026年Q2：SMTC 1.6T ACC芯片首次出货，板载线性均衡器从"教育期"进入"真实立项"，有源背板成为1.6T+必选项
  • 2026年5月：剑桥科技港股配售，揭示光模块竞争本质变化——融资能力成为核心壁垒
  • 阶段判断：800G处于成熟期（放量、价格下行）；1.6T处于快速成长期（Q2启动）；CPO/有源背板处于产业导入期（2026下半年-2027年放量起点）；相干光下沉处于概念期（2028中量产预期）

二、产业链结构全景

  • 上游：光芯片（CW激光器、EML、TIA、DSP）、电芯片（redriver/retimer）、PCB/基板、光纤预制棒
  • 中游：光模块（中际旭创、新易盛、剑桥科技）、光引擎/器件（仕佳光子、永鼎股份）、设备（科瑞技术、罗博特科）、互联方案（立讯精密、鸿腾精密、安费诺）
  • 下游：云厂商CSP（亚马逊、谷歌、微软、Meta、阿里、字节）、电信运营商、AI算力中心
  • 价值链分布：光芯片（毛利40-60%）＞光模块（毛利25-35%）＞设备（毛利20-30%）＞互联方案（有源化后毛利提升）
  • 国产替代进展：光模块——国产已主导全球（中际旭创全球第一）；光芯片——CW激光器/EML国产替代加速（仕佳光子、永鼎股份鼎芯光电）；高端DSP/TIA仍依赖海外（Marvell、Semtech）；设备——科瑞技术对标罗博特科，非标定制能力强

三、当前发展状态

  • 技术成熟度：800G已成熟；1.6T Q2启动放量（拐点确认）；CPO用高功率CW和FAU处于验证阶段（仕佳光子已开发成功，对标LITE国际领先）；有源背板从教育期→真实立项（20-25家CSP深度对接）
  • 商业化进度：剑桥科技配售资金用于核心部件战略性储备；仕佳光子CW激光器8月起kk级出货；科瑞技术客户Lumentum已放量，Finisar放量在即
  • 政策："东数西算"、算力基础设施建设政策间接拉动；无直接光通信产业政策

四、竞争格局、壁垒与政策环境

  • 光模块竞争格局：
  • 龙头：中际旭创、新易盛（800G放量，1.6T跟进）
  • A+H双平台独家：剑桥科技（港股唯一光模块标的，融资特权）
  • 追赶者：联特科技、德科立
  • 光芯片/器件格局：
  • CW激光器：仕佳光子（8月起kk级出货，CPO用高功率CW对标LITE）、永鼎股份鼎芯光电（CW光源放量，扩产中）
  • 设备：科瑞技术（非标自动化，绑定Lumentum/Finisar/华为）
  • 互联方案格局：
  • 电通道：立讯精密、鸿腾精密（有源化方案，1.6T+时代必选项）
  • 海外：安费诺、泰科、莫仕（鼎通科技绑定）
  • 进入壁垒：光模块——资金（锁料+全球化布局需巨量资金）、客户认证（海外大厂验厂最关注现金流）；光芯片——技术（MOCVD设备、工艺良率）、专利；设备——非标定制经验、客户关系
  • 关键变化：剑桥科技配售事件揭示——光模块竞争从"技术比拼"转向"资金+全球化平台"军备竞赛，A+H双平台的融资特权是独家壁垒

五、需求测算与空间展望

  • 光模块：1.6T Q2启动，LPO/LRO占整体出货占比1-2年内达25%。全球AI服务器1000万台，单台需多个1.6T光模块
  • CW激光器：仕佳光子8月起kk级出货（1kk=100万颗），短期新增2-3台MOCVD。主业400亿+CW激光器800亿=1200亿目标市值
  • 光模块设备：科瑞技术价值量占设备总投资60-80%，Lumentum已放量
  • 互联方案：有源化将大幅增加解决方案厂商价值量。2026下半年至2027年板载部署放量起点
  • CPO期权：仕佳光子CPO用FAU与大厂深度合作，市场尚未充分定价。相干光2028中量产
  • 敏感性：云厂商Capex增速（字节或上调至5000亿是积极信号）、1.6T升级节奏、LPO/LRO渗透率

六、商业模式升级路径

  • 光模块：从"可插拔光模块"（标准化产品，价格竞争）→"CPO共封装"（定制化，高附加值）→"光电融合解决方案"（平台化）。剑桥科技配售资金用于核心部件储备，正是为CPO/光电融合布局
  • 光芯片：从"单一CW激光器"→"CPO用高功率CW+FAU一体化"（价值量跃升）
  • 互联方案：从"被动线缆/背板"→"有源化电通道"（redriver/retimer/线性均衡器），价值量大幅提升。立讯精密、鸿腾精密受益
  • 定价权演变：光模块（价格接受者，毛利率下行）→光芯片（价格制定者，技术壁垒）→互联方案（有源化后超级定价权，不可替代）

七、认知偏差与市场博弈

  • 主流叙事陷阱：市场把光模块当作"周期性硬件"，忽视了A+H双平台融资特权的长期价值。剑桥科技配售折让仅8.88%显示市场认可度高，但部分投资者仍停留在"光模块就是代工"的认知
  • 共识与现实的鸿沟：机构一致预期1.6T 2026年放量，但Q2实际出货量可能不及预期（客户认证延迟）；CPO量产时间普遍预期2027年，但仕佳光子等已经拿到订单
  • 信息不对称：卖方看到产能规划和客户送样；买方看到股价波动和板块轮动；产业一线看到实际交付进度和良率——三方存在时滞
  • 反身性：光模块股价上涨→融资能力增强→锁料/扩产加速→市场份额提升（正反馈）。但如果AI算力需求增速放缓，库存积压风险大
  • 如果错了会怎样：若1.6T放量不及预期，中际旭创/剑桥科技估值回调；若CPO进展延迟，仕佳光子CPO期权归零；若云厂商Capex收紧（字节5000亿未确认），整个产业链增速下调

主题三：功率器件/被动元件涨价周期确认

一、概念的形成与演化

  • 起源：2023-2024年功率器件行业经历了价格战和库存去化，2025年AI算力+新能源+工业自动化需求爆发，供需格局逆转
  • 关键拐点：
  • 2026年2月5日：英飞凌第一轮涨价函（4/1生效）
  • 2026年5月28日：英飞凌第二波涨价函（7/1实施），直接把"需求超预期爆发"写进函件
  • 2026年5月：台积电计划下半年上调3nm报价，功率代工产能紧上加紧
  • 2026年5月：MLCC高容料号现货价5月已上涨70-80%，年初至今已涨20-30%
  • 阶段判断：功率器件和MLCC均处于涨价周期初期→中期过渡（从成本传导→定价权转移）

二、产业链结构全景

  • 功率器件上游：硅片/碳化硅衬底（天科合达、天岳先进）、晶圆代工（台积电、华虹、士兰微IDM）、封装材料
  • 功率器件中游：MOSFET/IGBT/SiC器件（英飞凌、ST、安森美、新洁能、士兰微、斯达半导）
  • 被动元件上游：镍粉（博迁新材）、离型膜（洁美科技）、陶瓷粉（国瓷材料）、MLCC设备
  • 被动元件中游：MLCC（村田、三星、风华高科、三环集团）、薄膜电容（法拉电子）、铝电解电容（艾华集团）
  • 下游：AI服务器（HVDC/SST）、新能源汽车、光伏逆变器、工业变频、消费电子
  • 价值链分布：功率器件——IDM（英飞凌毛利40%+）＞Fabless（新洁能毛利20-30%）；MLCC——高端高容（村田/三星，毛利50%+）＞中低端（风华/三环，毛利20-30%）
  • 国产替代进展：功率器件——MOSFET/IGBT国产替代率50%+，SiC MOSFET刚起步（新洁能量产第2/2.5代，650V-1700V）；MLCC——中低端国产替代率高，高端高容仍被村田/三星垄断（挤出效应20-25%）

三、当前发展状态

  • 功率器件：英飞凌两波涨价确认行业进入高景气；新洁能SiC平台已全面量产，第三代进入可靠性测试；HVDC和SST拉动SiC用量提升10倍
  • MLCC：高容料号现货价5月涨70-80%；产能缺口至少持续到2027年；Q2-Q3出厂价有望传导
  • 政策：新能源汽车、光伏、算力基础设施政策间接拉动；无直接功率/被动元件产业政策

四、竞争格局、壁垒与政策环境

  • 功率器件格局：英飞凌（全球龙头，涨价引领者）、ST/安森美（追赶）、新洁能（国产SiC MOSFET先锋，650V-1700V已量产）
  • MLCC格局：村田/三星/TDK（高端垄断）、风华高科/三环集团（国产替代主力，受益涨价周期）
  • 进入壁垒：功率器件——技术（SiC工艺良率）、资本（IDM模式重资产）；MLCC——设备精度（高端产能无法从中低端转产）、工艺良率、材料配方（村田专利壁垒）
  • 关键变化：英飞凌涨价函措辞从"成本传导"→"需求超预期爆发"，意味着行业定价权从下游→上游转移。台积电3nm涨价进一步强化"上游定价权"逻辑

五、需求测算与空间展望

  • 功率器件：HVDC对应功率器件价值量可能达10倍以上（相对传统方案）。SiC MOSFET是HVDC&SST首选（宽禁带、高效率）。新洁能看市值500亿+
  • MLCC：AI服务器单台4-5万颗，全球1000万台对应4000-5000亿颗。高端产能挤出效应20-25%（每增加1颗高端需减少2颗普通）。现货价涨70-80%→出厂价Q2-Q3传导
  • 敏感性：功率——AI算力Capex增速、新能源车渗透率；MLCC——AI服务器出货量、消费电子Q3备货力度

六、商业模式升级路径

  • 功率器件：从"价格接受者"（2023-2024年价格战）→"价格制定者"（2025-2026年涨价周期）。英飞凌引领，新洁能等跟随
  • MLCC：从"通用被动元件"（低毛利、同质化）→"AI专用高容料号"（高毛利、定制化）。产能结构重塑：高端产能稀缺，中低端过剩
  • 定价权演变：英飞凌拥有超级定价权（技术领先+品牌溢价）；新洁能在SiC领域拥有局部定价权（国产替代+产能稀缺）

七、认知偏差与市场博弈

  • 主流叙事陷阱：市场把功率器件涨价当作"成本推动"，忽视了英飞凌函件中"需求超预期爆发"的关键词——这是需求拉动型涨价，不是成本传导
  • 共识与现实的鸿沟：机构预期MLCC涨价到2027年，但如果海外大厂（村田/三星）扩产超预期，缺口可能提前收窄。实际上海外大厂扩产进度偏慢（设备精度要求高）
  • 信息不对称：卖方看到涨价函和产能规划；买方看到股价位置和估值；产业一线看到实际订单和交货周期——新洁能SiC平台已量产，但出货量能否跟上需求是未知数
  • 反身性：功率器件/MLCC涨价→相关企业盈利改善→扩产加速→供需缺口收窄→价格回落（负反馈）。但当前扩产周期（12-18个月）滞后于需求爆发，涨价周期至少持续1-2年
  • 如果错了会怎样：若AI算力需求增速放缓，英飞凌涨价可能无法完全传导；若新洁能SiC良率不及预期，市场份额被士兰微/斯达半导抢占；若MLCC海外大厂扩产超预期，涨价周期缩短
